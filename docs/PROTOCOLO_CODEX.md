# PROTOCOLO DE EJECUCIÓN CONTROLADA

1. Codex implementa. No redefine reglas.
2. Ante ambigüedad: `BLOCKED_BY_FUNCTIONAL_RULE`.
3. Standalone únicamente; SIGRF fuera de alcance.
4. No modificar estética, layout o navegación salvo orden explícita.
5. Cada orden debe entregar archivos modificados, tests, resultado, decisiones técnicas y bloqueos.
6. Ninguna orden se cierra con tests fallidos.
7. Moneda original nunca se pierde.
8. Una obligación económica se descuenta una sola vez.
9. Una empresa nunca financia a otra poniendo en riesgo sus propias necesidades.
10. El sistema propone; Tesorería decide.
